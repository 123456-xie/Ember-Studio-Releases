# Ember Studio（火种）

本仓库用于发布 Ember Studio 官方客户端安装包与版本说明。

## 下载

[Windows 2.1.9 预览版安装包](https://github.com/123456-xie/Ember-Studio-Releases/releases/download/v2.1.9/EmberStudio-2.1.9-Setup.exe) · [版本说明](https://github.com/123456-xie/Ember-Studio-Releases/releases/tag/v2.1.9)

当前 Windows/macOS 预览包的账户服务配置为 http://127.0.0.1:38080，适用于本机运行对应 sub2 服务的环境；公网用户使用前需要配置实际账户服务地址并重新打包。

Windows 使用 Setup.exe 安装向导。macOS Apple 芯片和 Intel 测试包均已提供，使用 DMG 安装。

## 版本说明

前往 [Releases](https://github.com/123456-xie/Ember-Studio-Releases/releases) 查看版本记录、适用环境和校验文件。请以对应版本说明为准。

## macOS 2.1.9 预览版

[下载 macOS 通用版](https://github.com/123456-xie/Ember-Studio-Releases/releases/download/v2.1.9/EmberStudio-2.1.9-mac-universal.dmg) · [通用版测试说明](https://github.com/123456-xie/Ember-Studio-Releases/releases/download/v2.1.9/EmberStudio-2.1.9-Mac-Universal-Testing.md)

通用版同时支持 Apple M 系列和 Intel。后台只有一个 macOS 安装包地址时，填写通用版的固定下载直链。

原分架构包：

[Apple 芯片版](https://github.com/123456-xie/Ember-Studio-Releases/releases/download/v2.1.9/EmberStudio-2.1.9-mac-arm64.dmg) · [Intel 版](https://github.com/123456-xie/Ember-Studio-Releases/releases/download/v2.1.9/EmberStudio-2.1.9-mac-x64.dmg)

Mac 测试包保留本机账户服务地址，使用 ad-hoc 签名，未做 Apple Developer ID 签名或公证。下载对应芯片的 DMG，并阅读 [Mac 测试说明](https://github.com/123456-xie/Ember-Studio-Releases/releases/download/v2.1.9/EmberStudio-2.1.9-Mac-Testing.md)。
